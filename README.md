# 크리AI티브 랩 | 크리에이티브 스튜디오 웹사이트

AI 기반 이미지·영상 생성 교육과 워크숍을 제공하는 크리에이티브 스튜디오 랜딩 페이지

## 🎨 프로젝트 소개

크리AI티브 랩은 생성형 AI를 활용한 실무 중심 교육과 워크숍을 제공하는 크리에이티브 스튜디오입니다. 이 웹사이트는 디자이너, 크리에이터, 기업을 위한 AI 교육 서비스를 소개하는 랜딩 페이지입니다.

## ✨ 주요 기능

- 🎯 **반응형 디자인**: 모바일, 태블릿, 데스크톱 완벽 지원
- 🌙 **다크 테마**: 미래지향적인 어두운 배경에 그라디언트 악센트
- ✨ **스크롤 애니메이션**: Intersection Observer API를 활용한 부드러운 페이지 전환
- 🎨 **CSS 그라디언트 디자인**: 이미지 파일 없이 순수 CSS로 구현된 비주얼
- 📱 **완전 독립형**: 외부 라이브러리 없이 단일 HTML 파일로 작동

## 🚀 주요 서비스

1. **AI 이미지 생성 워크숍** - Midjourney, DALL-E, Stable Diffusion
2. **AI 영상 제작 과정** - Runway, Pika, Luma AI
3. **기업 맞춤 교육** - 디자인팀, 마케팅팀 AI 워크플로우
4. **공간 디자인 AI** - 건축·인테리어 렌더링
5. **1:1 컨설팅** - 개인 크리에이터 포트폴리오 제작
6. **AI 툴 마스터** - 최신 AI 크리에이티브 도구 교육

## 📂 파일 구조

```
webpage/
├── index.html          # 메인 랜딩 페이지 (모든 코드 포함)
└── README.md          # 프로젝트 설명 (이 파일)
```

## 🛠️ 기술 스택

- **HTML5**: 시맨틱 마크업
- **CSS3**:
  - CSS Custom Properties (CSS 변수)
  - Flexbox & Grid 레이아웃
  - 그라디언트 & 애니메이션
  - 반응형 미디어 쿼리
- **JavaScript (Vanilla)**:
  - Intersection Observer API (스크롤 애니메이션)
  - DOM 조작

## 🌐 사용 방법

### 로컬에서 보기
1. 저장소 클론:
   ```bash
   git clone https://github.com/shine2122/webpage.git
   cd webpage
   ```

2. 브라우저에서 열기:
   - `index.html` 파일을 더블클릭
   - 또는 브라우저 주소창에 `file:///path/to/index.html` 입력

### 로컬 서버로 실행
```bash
# Python 3 사용
python3 -m http.server 8000

# 브라우저에서 http://localhost:8000 접속
```

### GitHub Pages로 배포
1. GitHub 저장소 Settings → Pages
2. Source를 메인 브랜치로 설정
3. `https://shine2122.github.io/webpage` 에서 접속 가능
